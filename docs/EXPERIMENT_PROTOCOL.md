# Experiment protocol

For every meaningful experiment, record:

- Hypothesis / question.
- Git commit or version.
- Random seed and configuration.
- Duration (ticks).
- Organism age, energy and food eaten.
- Births, deaths, extinction and trait diversity once those systems exist.
- Results from multiple seeds before making general claims.

The current prototype uses seed `42` and displays age, energy and food eaten on screen. It has one organism and no reproduction yet.
