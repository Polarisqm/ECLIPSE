# ECLIPSE roadmap

## Prototype 0.2 — first observable organism
- [x] A 2D grid world with food and rocks.
- [x] One organism with energy, age and food-consumption metrics.
- [x] Simple perception: locate food within a limited Manhattan distance.
- [x] Basic movement and obstacle avoidance.
- [x] Energy cost, eating and limited food regrowth.
- [x] Reproducible random seed for repeatable experiments.

## Next milestones
1. Add automated tests for movement, energy and eating.
2. Separate perception, decision-making and action into explicit modules.
3. Add several organisms and compare behavior.
4. Add reproduction, inherited traits and mutation.
5. Add a Python/Pygame visualization and experiment metrics.
6. Add memory/learning only after the baseline ecosystem is measurable.
